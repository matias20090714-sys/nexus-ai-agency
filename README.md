# 🚀 NEXUS AI - Sistema Operativo de Agencia de Inteligencia Artificial (White-Label)

**NEXUS AI** es una plataforma integral de **Marca Blanca ("Agency in a Box")** diseñada para que emprendedores, agencias y consultores creen, vendan y operen su propia Agencia de Automatización con Inteligencia Artificial para empresas locales y globales.

---

## 🌟 Características Principales

### 🏢 1. Arquitectura Multi-Agencia con Aislamiento Total (Multi-Tenant)
* Permite crear múltiples agencias independientes.
* Cada agencia tiene sus propios clientes, leads, bases de datos y facturación mensual sin cruzarse jamás con otras cuentas.

### 🤖 2. Motor de Inteligencia Artificial en Vivo
* Integración nativa con **Google Gemini (1.5 Flash / 2.5 Flash / 3.7 Flash)** y soporte para OpenAI / Groq.
* Respuestas en menos de 2 segundos adaptadas al contexto y tono de cada industria.

### 📱 3. Conexión Real con WhatsApp Cloud API (Meta Oficial)
* Envío y recepción de mensajes de WhatsApp en tiempo real.
* Configuración de Webhooks para atención automatizada 24/7.

### 🌐 4. Web Comercial & Portafolio de Servicios
* Landing page pública personalizable lista para compartir con clientes potenciales.
* Muestra los 4 servicios clave de la agencia y los paquetes de suscripción ($290 - $690 USD/mes).

### 🎓 5. Manual Maestro de Ventas & Cierre B2B
* Playbook interactivo personalizado con el nombre de tu agencia y el tuyo.
* Guiones paso a paso para prospección por WhatsApp (El mensaje "Caballo de Troya"), estructura de demos en video de 60 segundos y manejo de objeciones.

### 🔥 6. Reactivador de Clientes Inactivos (Oferta Irresistible)
* Diseñador de campañas relámpago para generar ventas en 48 horas reactivando bases de datos de WhatsApp.
* Calculadora de ganancias y generador de contratos formales de servicios B2B.

---

## 🚀 Instalación y Despliegue Local

1. **Requisitos:**
   * Node.js instalado (v18 o superior).

2. **Iniciar el Servidor:**
   ```bash
   node server.js
   ```

3. **Abrir la Plataforma:**
   Ingresa en tu navegador a:
   ```
   http://localhost:5180/
   ```

---

## ⚙️ Configuración de APIs

* **Google Gemini API:** Obtén tu clave gratuita en [Google AI Studio](https://aistudio.google.com/app/apikey).
* **WhatsApp Cloud API:** Obtén tu Phone Number ID y Token en [Meta Developers](https://developers.facebook.com/).
